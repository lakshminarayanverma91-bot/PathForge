The Story Behind
Pathforge

We were three students tired of fragmented tools, expensive coaches, and platforms that didn't understand the real pressures of student life. So we built Pathforge.

Our Mission

Democratising growth for every ambitious student

Pathforge was born from a simple frustration: the tools that actually help students succeed — interview coaches, startup mentors, career advisors, and wellness counsellors — are expensive, inaccessible, or scattered across a dozen platforms.

"What if every student, regardless of their institution or background, had access to an always-on AI that genuinely understood their journey?"

That question became our north star. We set out to build a single, unified platform powered by Google Gemini where every module — from mock interviews to mental wellness — is purpose-built for the student experience, completely free at its core, and radically transparent about how it works.

Builders Behind It
Our Journey

From a hostel room to a full platform

January 2024 · The Spark
Three students, one shared frustration
Rohan, Priya, and Aditya were sitting in their college library the night before campus placements, realising how unequal the preparation game was. Some peers had paid coaches; most didn't. A whiteboard sketch later, the concept of Pathforge was born.
April 2024 · First Module
CrackAI goes live as a prototype
The first working version of CrackAI launched internally within their college with 40 test users. The feedback was overwhelming — students wanted more modules. Gemini's API had just opened up, and the team pivoted from a single-tool to a full ecosystem.
August 2024 · The Platform Takes Shape
VentureIQ, CampusPath, and MindMate ship
Over one intense summer, the team designed and shipped three new modules, refining the design language, building the bento grid UI, and integrating GitHub for CampusPath. The unified Pathforge platform was born, running entirely on Google Gemini.
2025 · Today & Beyond
v2.0 live — and growing fast
Pathforge v2.0 launched with a complete visual and architectural overhaul. The team is now expanding university partnerships, exploring a freemium model, and actively building the open-source community around the project. The mission hasn't changed: every student deserves access to tools that help them grow.
The Stack

Built on rock-solid foundations

🤖
Google Gemini
All AI inference — real-time scoring, SWOT generation, roadmap planning, and burnout analysis — runs on Gemini's API, chosen for its superior contextual understanding.
Core AI Engine
🐍
Django + Python
The backend is built in Django with Python — fast to iterate, battle-tested, and the natural choice for a student team that needed to ship quickly without sacrificing reliability.
Backend Framework
⚡
Vanilla JS + CSS Custom Props
The frontend is intentionally lightweight — no heavy frameworks, just performant vanilla JS, CSS variables, and hand-crafted animations for a premium feel at zero bundle cost.
Frontend Layer
GitHub API
CampusPath integrates with the GitHub API to read your public repository activity and factor real coding progress into personalised week-by-week learning roadmaps.
CampusPath Integration
🛡
Privacy-by-Design
All sensitive data — especially MindMate journal entries — is processed in memory and never persisted. Session tokens expire immediately. No third-party analytics on sensitive pages.
Security Layer
☁
Cloud & Open Source
Deployed on scalable cloud infrastructure with full CI/CD pipelines. The entire repository is public on GitHub — community contributions and forks are actively welcomed.
